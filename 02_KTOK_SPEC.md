# 🎵 kTok Specification (Prompt Brief for Gemini 3.8 Flash)

> **Назначение файла:** Скопируй содержимое этого файла в первый запрос отдельного чата по разработке мода **kTok**.

---

## 🎯 Роль и задача
Ты — специалист по Android-моддингу и реверс-инжинирингу. Мы создаем **kTok** (мод TikTok от **kipsway**), основанный на архитектуре патчей `MargyT` и `ReVanced`.

## 📦 Целевые характеристики мода
1. **Название:** `kTok`
2. **Авторский тег:** `by kipsway`
3. **Пакет:** `com.kipsway.ktok` (устанавливается рядом с официальным клиентом TikTok).
4. **Ключевой функционал:**
   - **Снятие водяных знаков:** Прямое скачивание видео в высоком качестве без водяного знака TikTok и логотипа в конце.
   - **Обход региональных ограничений (Region Spoofing):** Просмотр и публикация видео без необходимости вытаскивать SIM-карту (подмена кода страны).
   - **Вырезание рекламы:** Полное удаление спонсированных роликов из бесконечной ленты `For You`.
   - **Скачивание аудио:** Возможность скачать аудиодорожку ролика в формате `.mp3`/`.aac`.
   - **Оформление:** Адаптация под Material You 3 и темную палитру «Мозаика».

---

## 🛠 Технический стек и инструменты
- **Инструмент патчинга:** `ReVanced CLI` + кастомные smali/dex-патчи из репозитория `MargyT`.
- **Автоматизация:** GitHub Actions workflow для автоматической компиляции и подписи APK при выходе новых версий TikTok.
- **Подпись (Keystore):** Единый ключ `kipsway.keystore` для бесшовных обновлений через `kStore`.

---

## 📋 Пошаговый план разработки для Flash
- **Шаг 1:** Анализ манифеста и ресурсов (`AndroidManifest.xml`, `strings.xml`) для смены имени на `kTok` и пакета на `com.kipsway.ktok`.
- **Шаг 2:** Настройка конфигурации патчей: отключение водяных знаков, фикс региона, скрытие рекламы.
- **Шаг 3:** Подготовка иконки `kTok` (минималистичная иконка в сквиркле, цвета `#0A0A0C` и лавандовый `#B8A7F0`).
- **Шаг 4:** Скрипт сборки на Bash / PowerShell для локального патчинга чистого APK через `revanced-cli`.
- **Шаг 5:** Готовый CI/CD workflow (`.github/workflows/build_ktok.yml`) для сборки в облаке и выгрузки релиза в GitHub Releases.
