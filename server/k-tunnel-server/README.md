# 🚀 Серверный стек k-Tunnel (by kipsway)

Автоматизированный серверный стек для развертывания персональных высокоскоростных нод **k-Tunnel** для клиентов **kTube**, **kWitch** и **kGram**.

---

## ⚡ Быстрый старт на VPS (В одну команду)

Подключитесь к вашему серверу по SSH (Debian 11/12 или Ubuntu 22.04/24.04) и выполните:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd s/server/k-tunnel-server
chmod +x deploy_vps.sh
./deploy_vps.sh
```

Скрипт автоматически:
1. Включит сетевой алгоритм **BBR** ядра Linux для быстрой передачи 4K-потоков.
2. Установит Docker (если не установлен).
3. Поднимет **sing-box** с протоколами:
   - **VLESS-Reality** на порту `443` (маскировка под Apple iCloud Gateway).
   - **Shadowsocks-2022** на порту `8388` (резервный защищенный протокол).
4. Запустит легковесный API-сервер подписки на порту `8080`.
5. Выведет готовую ссылку подписки вида:
   ```
   http://YOUR_SERVER_IP:8080/sub
   ```

---

## 📱 Интеграция в kTube и kWitch

Полученную ссылку подписки можно вставить:
- В **kStore** (Настройки -> Источник подписки k-Tunnel).
- В **kTube** (Настройки kTube -> Ускорение k-Tunnel -> Обновить подписку).
- В конфигурационный файл `ktube/k-tunnel/config/tunnel_config.json`.

Клиенты автоматически подтянут ваш личный сервер с минимальным пингом.
