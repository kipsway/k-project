# 💬 kGram — Telegram Fork by kipsway

> **Архитектура:** База NimarkoGram (Telegram 13.2.2) + Палитра «Мозаика» + Плеер RX Playa  
> **Имя пакета:** `org.kipsway.kgram` (параллельная установка с официальным клиентом)  
> **Фирменные цвета:** Оникс `#0A0A0C`, панели `#0F0F12`, лаванда `#B8A7F0`, активная рамка `#7E6FC4`

---

## ⚡ Функционал
1. **Тема «Мозаика» по умолчанию:** Никаких серых засветов — глубокий оникс `#0A0A0C` и лаванда `#B8A7F0` из Chatterino+ (chat.eblo.id).
2. **Аудиоплеер RX Playa:** Полноэкранный плеер с крупной обложкой со сквирклом 28dp, виньетированием и свайпами.
3. **Инструменты приватности:** Призрачный режим, скрытие индикатора набора текста («печатает...»), сохранение удаленных сообщений.
4. **Медиа-инструменты:** HD-кружочки CameraX без потери битрейта.
5. **Человеческие настройки:** Меню называется нативно «Настройки kGram» с простыми описаниями на русском языке.

---

## 📁 Структура файлов
```text
kgram/
├── theme/
│   ├── mozaik.attheme          # Официальный файл темы Telegram
│   └── MozaikThemeManager.java  # Программная активация темы при первом запуске
├── player/
│   └── RxPlayaPlayerView.java  # Экран плеера музыки в стиле RX Playa
├── settings/
│   ├── KGramConfig.java        # Реестр настроек в SharedPreferences
│   └── KGramSettingsFragment.java # Меню «Настройки kGram»
├── res/
│   ├── values/strings.xml      # Fallback строки
│   └── values-ru/strings.xml   # Русские человеко-понятные названия
└── scripts/
    ├── setup_kgram.ps1         # Подмена пакета и изоляция провайдеров (PowerShell)
    └── setup_kgram.sh          # Подмена пакета и изоляция провайдеров (Bash)
```
