# 📺 kTube — Руководство по сборке (by kipsway)

## 📌 О проекте
**kTube** — кастомный клиент YouTube от **kipsway** без рекламы, со встроенным SponsorBlock и встроенным сетевым ядром **k-Tunnel** для гарантированного обхода замедления (DPI) и воспроизведения вплоть до 4K без внешних VPN-приложений.

- **Пакет:** `com.kipsway.ktube` (ставится рядом с официальным YouTube).
- **Вход в аккаунт:** Поддержка MicroG / GmsCore (`app.revanced.android.gms`).
- **Дизайн:** Формула «Жидкое стекло + Material You 3 + акценты Chatterino+» (чистый оникс `#0A0A0C`, панели `#0F0F12`, лаванда `#B8A7F0`).
- **Сетевое ядро:** Встроенный loopback-прокси `127.0.0.1:10808` (SOCKS5), селективное ускорение потоков `*.googlevideo.com`.

---

## 🚀 Быстрый старт сборки

### 1. Подготовка базового APK YouTube
Скачайте чистый APK YouTube (рекомендуемые версии: `19.34.42` или `19.43.41`, архитектура `arm64-v8a` или `nodpi`) с проверенного источника (например, APKMirror) и положите его в папку:
```
ktube/build/input/youtube.apk
```

### 2. Запуск сборки
* **Вариант 1 (Двойной клик):** Запустите `ktube/build/build_ktube.bat`.
* **Вариант 2 (PowerShell):**
```powershell
cd C:\Users\ДДД\Desktop\s\ktube\build
.\build_ktube.ps1
```

Скрипт автоматически:
1. Проверит окружение JDK 21.
2. Скомпилирует модули k-Tunnel и оверлея плеера.
3. Применит ReVanced патчи с переименованием пакета в `com.kipsway.ktube`.
4. Внедрит тему «Оникс + Лаванда» и мозаичную иконку.
5. Подпишет готовый APK релизным ключом `kipsway.keystore`.
6. Сохранит релизный APK в `ktube/build/output/kTube-v1.0.0-kipsway-release.apk`.

---

## 🔑 Данные релизного ключа
* **Хранилище:** `ktube/build/kipsway.keystore`
* **Alias:** `kipsway`
* **Пароль хранилища/ключа:** `kipsway2026`
* **Алгоритм:** RSA-2048 / SHA256withRSA (срок действия: 10 000 дней)

## 🛠 Структура исходного кода
```
ktube/
├── patches/            # Конфигурация патчей и цветовые ресурсы Оникс + Лаванда
├── k-tunnel/           # Сетевое ядро, loopback-демон и хуки Cronet/OkHttp

└── build/              # Скрипты сборки, keystore и выходная папка
```
